# OneShotPress - Before/After 画像証跡作成ツール (MVP)

このアプリケーション (OneShotPress) は、開発業務における画面キャプチャの取得、整理、Excelへの貼り付け作業を効率化するためのツールです。フォルダ内の画像を自動的にペアリング（例：`_b` と `_a`）し、証跡資料としてExcel形式で出力します。

## 主な機能

*   **フォルダ選択**: 証跡画像が含まれるフォルダを選択します。
*   **自動ペアリング**: 選択したフォルダ内の画像ファイル名から、改修前・改修後・補足の最大3枚の画像を自動的に判定・ペアリングします。
*   **一括リネーム機能**: リスト下部のボタンから、選択した画像に識別子を一括で付与し、ペアリングの手間を省くことができます。
*   **ペア一覧・サムネイル表示**: ペアリング結果をリスト表示し、画像のサムネイルを確認できます。不足している画像がある場合はエラーメッセージを表示します。
*   **ドラッグ＆ドロップ並び替え**: 出力前の画像ペア一覧を、ドラッグ＆ドロップで直感的に並び替えることができます。
*   **識別子・出力設定のカスタマイズ**: ペア判定の文字列（`_b` や `_a`）や、Excelのヘッダー文言、シート名、各列の背景色、氏名、よく使うシステム名を自由に設定できます。
*   **ファイル名の自動生成**: 出力されるExcelファイル名は `YYMMDD-【氏名】システム名-主題.xlsx` というルールに従い、設定に応じて自動生成されます。
*   **Excel出力**: ボタン一つで、自動調整された画像付きのExcelファイルを生成します。セル結合を行わない自由なレイアウトを採用しています。
*   **ダークモード対応**: UIはライトモードとダークモードの両方に対応しており、画面右上のアイコンからシームレスに切り替えることができます。

## 技術スタック

*   **フロントエンド**: Svelte, TypeScript, Vite, Tailwind CSS, bits-ui
*   **バックエンド**: Rust, Tauri v2
*   **Excel生成**: rust_xlsxwriter

## 開発・実行方法

### 前提条件

Tauri v2の開発環境が必要です。詳細は[公式ドキュメント](https://tauri.app/v1/guides/getting-started/prerequisites)を参照してください。

### 依存関係のインストール

```bash
npm install
```

### 開発用サーバーの起動

ホットリロード対応の開発モードでアプリを起動します。

```bash
npm run tauri dev
```

### アプリケーションのビルド

リリース用のデスクトップアプリケーションをビルドします。

```bash
npm run tauri build
```

ビルドされた実行ファイルは `src-tauri/target/release/bundle/` 以下に出力されます。
